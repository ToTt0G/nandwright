## Your course folder is all you need

Nandwright works on the folder layout the course gives you:

```
nand2tetris/
  projects/
    01/   And.hdl  And.tst  And.cmp  ...
    02/
    ...
```

It does not use the `tools` folder and it does not need Java. The simulators,
the assembler, the emulators and the Jack compiler are built into the extension.

No course folder yet? Download the project files from
[nand2tetris.org/software](https://www.nand2tetris.org/software), or try the
example chip to see how it works.
