## Hand in a project

**Nand2Tetris: Set Up…** asks three things, and you can skip any of them:

- **Your course.** A course preset knows how the course numbers its projects,
  which folders make up each one, how the zip must be named and which files go in.
  Without a preset, you set these yourself in the `nandwright.zip` settings.
- **Your name**, for the zip's name. It is kept in your user settings only.
- **Your grade sheets.** Choose the sheets you downloaded and they are copied into a
  folder named `grade-sheets` in your workspace. A sheet already there is never
  replaced without asking.

Then use **Zip Project for Hand-In**: from the status bar, the editor's `…` menu or
the Explorer's right-click menu. The list shows every file. What your course asks
for is ticked, and so is the project's grade sheet, with the date it last changed.
The button on the sheet opens it, so you can fill it in before you save the zip.
