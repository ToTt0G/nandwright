## Run the test script

Every `.tst` file is a test. Three ways to run one:

- the **play button** at the top right of a `.hdl` or `.tst` editor
  (`Ctrl+Alt+T`, `Cmd+Alt+T` on a Mac);
- **Run test** above the `CHIP` line;
- the **Testing** view (the flask icon in the activity bar), which runs a
  whole project folder at once.

A pass means the same as "Comparison ended successfully" in the official
simulator. The test also writes the `.out` file next to the script, as the
official tools do.
