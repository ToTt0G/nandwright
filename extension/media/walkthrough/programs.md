## Later projects: assembly, VM code and Jack

Open a program and choose **Run Program** from the play button's menu:

- `.asm` and `.hack` run on the Hack computer (the CPU emulator);
- `.vm` files and Jack programs run on the VM emulator, with a built-in OS for
  whatever your program does not define.

The panel shows the **screen**, the registers, the stack and memory. Click the
screen to type on the Hack keyboard. Breakpoints you set in the editor pause the
program, and the line about to run is highlighted.

When you write your own assembler, VM translator or compiler, open the file it
produced and run **Compare with Reference Output** to see where it differs.
Nandwright never overwrites your tool's output without asking.
